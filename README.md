# 🎮 Rock–Paper–Scissors (CLI)

A simple command-line implementation of the classic Rock–Paper–Scissors game written in Python.
This project demonstrates basic game loop structure, input validation, and simple decision logic.

## 🧠 Game Logic:

- The winner is determined using predefined classic winning combinations;
- The game continues until the user enters Q to quit.

## 📌 Notes:

This is a basic console project focused on clean structure and simple control flow logic.

## 🛠 Requirements:

This project uses only Python’s standard library.
